Project Overview
SneakNova is a fictional premium sneaker retail organisation created as part of a Web Development project. The website is created to provide customers with a simple and engaging way to explore different sneaker brands and styles in one place.

The website focuses on popular sneaker brands such as Nike, Adidas, Puma, New Balance and Converse. It provides information about the organisation, displays sneaker products and images, and allows customers to find contact and enquiry information.

The website is being developed using basic HTML during Part 1 of the project. Upcoming parts of the project will introduce additional web technologies and functionality.

Website Goals and Objectives
The main goal of the SneakNova website is to create a user-friendly online presence for a fictional sneaker retail store.

The website aims to:

Provide information about SneakNova.
Display different sneaker brands and products.
Allow visitors to view sneaker images and prices.
Provide an online gallery of sneaker styles.
Make it easy for customers to find contact information.
Allow customers to make product enquiries.
Provide simple and clear navigation between website pages.

Key Features and Functionality
The current Part 1 website includes the following features:
Home Page – Introduces SneakNova and includes a promotional video, brands and selected products.
About Us Page – Provides information about SneakNova, including its story, mission, vision and values.
Products Page – Displays selected sneakers, brands and prices.
Gallery Page – Displays images of different sneaker styles.
Enquiry Page – Provides information about making product enquiries.
Contact Us Page – Provides SneakNova's contact and location information.
Navigation Menu – Allows users to move between the different pages.
Images and Video – Used to make the website more visually engaging.
